## 游玩时长目标（重要·体量重定位）

本剧本是**游戏脚本**而非长篇互动小说——目标是让玩家**单条路径在 30 分钟内通关**：
- **每个时空**（赛博段 / 民国段）独立游玩 **8-12 分钟**
- **现实回廊**（S01 + S07 + S14）合计 **5-7 分钟**
- **基础真终结局 E01 一条路径**：21-31 分钟 ✅
- **真·想见你 E02 一条路径**（含 S15 真告白长卷）：26-39 分钟（条件性奖励多停 5-8 分钟看完整告白，可接受）

字数预算按 **200 字/分钟 AVG 有效阅读速度**反推（已扣除演出/选择/转场所占的隐性时间约 20-25%）。

## 写作顺序建议（拓扑序，含并行优化）

> **优先级原则**：先把汇合点（S07、S14）之前所有上游写完，再写汇合点本身；段落变体（S06a/b、S13a/b）可以同人在阶段内并行写以保持气质一致。

### 阶段 1 · 序章与赛博段（S01 → S06a/b）

```
顺序：
1. S01（必先写，奠定整本气质 + 信物缺席状态）
2. S02 → S03 → S04 → S05（赛博主线一次走通；保持累积爱意锚点的语气连贯）
3. S06a + S06b（同人并行写，两个段落 BE 的对比张力要靠同一个作者抓）
```

**阶段产出**：7 场、约 2,000–3,300 字

### 阶段 2 · 现实回廊（S07）

```
顺序：
4. S07（汇合点；写时要兼顾"刚从 S06a 来的玩家"与"刚从 S06b 来的玩家"两种情绪余韵——见 S07 描述）
```

**阶段产出**：1 场、约 200–350 字

### 阶段 3 · 民国段（S08 → S13a/b）

```
顺序：
5. S08 → S09 → S10 → S11 → S12（民国主线一次走通；S09 的"未烧的信"伏笔要在 S10 显式回收）
6. S13a + S13b（同人并行写——"她敢说陪他承担" vs "她替他选放手"的两种残念色调要靠同一个作者抓）
```

**阶段产出**：7 场、约 2,100–3,000 字

### 阶段 4 · 终章（S14 + S15）

```
顺序：
7. S14（极简版·所有路径都到这里·E01；写时要克制——只有四件事：最后一个愿望、吹蜡烛、淡化、生日快乐）
8. S15（条件性奖励·E02；写时要把 S15 当成"S14 之后玩家不知道还有的隐藏关卡"——画面浮现一封信、一段告白、一段想象画面长卷、一句"这一次，我来找你"）
```

**阶段产出**：2 场、约 900–1,700 字

### 总进度（4 阶段）

- **17 场**、约 **60–90 个画面**、约 **5,000–9,000 字**（17 场内容之和）
- **单条路径游玩 21-39 分钟**（E01：21-31 分钟 / E02：26-39 分钟）
- 可串行（一人写 17 场，预计 1-2 个工作日完成） / 可并行（按段落分包给多人——但务必同人写同段落变体以保气质）

## 单场写作流程（每场都按这个 Checklist 走一遍）

```
□ 1. 读 01-大纲.md 中本场对应行（核心事件 / 上游 / 出口 / 累积锚点说明）
□ 2. 读 00-人物档案.md 中本场涉及角色的"说话风格 / 标志动作 / 信物归属"段落
□ 3. 检查"三件信物时空可见性表"——确认本场哪些信物可见、哪些不可见
□ 4. 列本场画面提纲（仅画面短标题清单，3-5 分钟搞定）
□ 5. 按提纲逐画面写四部分：画面描述 → 背景旁白·按需 → 对话·含选择型对话 → 转场（跨世界切换时用富过渡）
□ 6. 末画面写好"→ 跳转: Sxx Frame Y.Z" 或 "→ [结局: Exx]"
□ 7. 自检：
    □ 三件信物可见性是否正确？
    □ 男主台词是否符合"温柔/帅气/直接/撩"且不油腻？
    □ 女主是否不主动哼歌、不主动念那句诗？害羞反应是否多用动作（低头/耳尖泛红/按指尖）而非每次都"呀……"？
    □ 累积爱意锚点是否含 1-2 个轻量选项（不切场）？
    □ 命运分叉点是否含一个显式选项（含两条出口）？
    □ 末画面是否有钩子？
    □ **每帧是否四块齐全且顺序正确（画面描述 → 背景旁白·按需 → 对话 → 转场）？画面描述是否只写"场景 / 人物 / 微动效"3 大子类，视角作为「场景」标签，转场已移出？**（见 `interactive-game-scene-format.mdc` §二 + §2.1）
    □ **画面描述是否只写"静帧 + 微动效"？人物连续动作序列（她笑→他笑）是否在对话动作括号里？重大角色移动（他绕到你身侧）是否放在 §2.4 转场块里？**（见 §2.1 核心原则）
    □ **「场景」是否标注了视角（【第三人称】 / 【FPV·你的视角】 / 【特写】 等）？亲密节点（近距离对望、被靠近、被表白）是否选用了 FPV？**（见 §2.1 视角段）
    □ **背景旁白是否"按需出现"？流畅的画面 + 对话已经讲清的，是否省略了 `### 背景旁白` 标题块？**（见 §2.2 重要原则）
    □ **选项是否已嵌入对话块（"——【选择·xxx】——"格式），而非另起一个"### 互动选项"标题块？是否以对话格式呈现差异（她具体行 + 他具体反应行），而非抽象"微差异"？影响是否"略微"（不切场情况下典型 1-2 行不同）？分支后是否可以接共同的单线后置对话？**（见 §2.3.2 + §2.3.3）
```
