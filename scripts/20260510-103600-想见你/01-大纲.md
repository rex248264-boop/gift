# 《想见你》大纲（分支树）

## 基本信息
- **题材**：言情 / 软科幻穿越 / 跨时空守护
- **预计场次数**：**16 场（基础）+ 1 场（S15 条件性奖励）= 16-17 场**
- **游玩时长目标（重要·体量重定位）**：本剧本是**游戏脚本**而非长篇互动小说——目标是让玩家**单条路径在 30 分钟内通关**：
  - 每个时空（赛博段 / 民国段）独立游玩 **8-12 分钟**
  - 现实回廊（S01 + S07 + S14）合计 **5-7 分钟**
  - **基础真终结局 E01 一条路径**：21-31 分钟 ✅
  - **真·想见你 E02 一条路径**（含 S15 真告白长卷）：26-39 分钟（条件性奖励多停 5-8 分钟看完整告白，可接受）
- **目标字数（按 200 字/分钟 AVG 有效阅读速度反推）**：
  - **每场字数预算 100-1500 字**（具体见 `02-写作计划.md` 的「场次画面预算总表」）
  - **单条最短路径**（S06b + S13b·E01）：3500-4500 字
  - **单条最长基础路径**（S06a + S13a·E01）：4200-6000 字
  - **单条真·想见你路径**（S06a + S13a + S15·E02）：5000-7500 字
  - 总场次集合（17 场全部内容之和）：5000-9000 字
- **写作格式**：见 `.cursor/rules/interactive-game-scene-format.mdc`——画面式拆解，每画面四部分（画面描述/背景旁白/对话/互动选项）；剧本字数远少于传统纯文本剧本，因为游戏靠**画面 + 立绘 + 演出 + 配音**共同承载叙事
- **三蜡烛结构（镜像骨架）**：S01 吹灭**第一根**蜡烛 → 进入赛博；S07 吹灭**第二根**蜡烛 → 进入民国；S14 吹灭**第三根**蜡烛 → 男主淡化消失、化作一句「生日快乐，姐姐」。三次"吹蜡烛"是全剧本的骨架节拍，每一次都对应一次"被现实之外的世界接管"或"被拉回现实"的视觉转场。**S14 之后**：若玩家走的路径是 **S06a + S13a**（赛博段高爱意触发钻戒显形 + 民国段「我陪他承担」触发婚礼达成）→ 解锁 S15 真告白与想象未来；否则游戏在 S14 完结，留下未解之谜与未尽的余韵
- **玩家代入**：玩家就是「**她**」（28 岁生日寿星，女主）。剧本旁白中以**第二人称"你"**指代她；男主在剧本中以**「他」**出现。所有命运选项都从**她的视角**设计、由她做出
- **核心冲突**：现实中"她"与"他"是网恋恋人，因为某些原因（现实阻隔/身份/距离）至今未能真实相见——这本身就是一段被现实阻隔的"禁忌之恋"。今天是她 28 岁生日，"他"依然无法真实到场。为了在某种意义上抵达她，"他"用两种方式抵达平行时空中的"自己"：**赛博段是"意识入侵"**（现实他的意识强行叠加到赛博他身上，赛博他出现"赛博精神病"征兆），**民国段是"亲身穿越"**（现实他以陌生访客的实体形态出现，与民国他面对面对谈一夜后默默消散）。每一次抵达都伴随代价。**民国段的禁忌之恋是现实关系的主题镜像**——剧本以"在所有不允许我们相见的世界里他都拼命想抵达她"作为情感骨架
- **关键叙事原则（潜文本克制·零点破写法）**：本剧本所有伏笔——陌生访客身份、金珠子的循环传承、白金钻戒的求婚信物身份、四叶草耳钉的设计来历、那句私密暗语的完整版、赛博·他奇怪征兆的起源即"现实他意识叠加"——**在 S15 真告白之外的所有正文场次中都不应被点破**。所有"叠加意识""穿越""他是从另一个时空来的""那是求婚信物""那对耳钉是现实他想给的"等点破真相的字眼，**禁止出现在剧本正文的 `### 画面描述` / `### 背景旁白` / `### 对话` 块里**——只能通过画面、微动效、人物自己也不明所以的感应、不完整的半句、说不清的"心口酸"等潜文本手法承载，让玩家感到"什么不对但说不清"，而不是"我已经看懂这是穿越/叠加意识了"。元描述（核心事件、摘要、自检备注、精简记录）里可以点破（这些是给写作者看的）——但即便是元描述也应尽量克制表述，避免诱导写作者把点破写进正文。**这条原则保证 S15 真告白那封信揭穿所有真相时的回收冲击不被提前稀释**。除非用户主动要求加入某处提前点破。
- **关键叙事原则（最大伏笔·条件性揭穿）**：民国段中**绝不点破**"陌生访客"就是穿越来的现实他——而且更彻底的是：**陌生访客与民国·他的整场对谈完全发生在剧本之外、镜头之外**（在 S10 暴雨之后、S11 邮轮密约之前的某个夜里，地点、过程、台词、那句关键反问，剧本永远不正面呈现）。玩家在 S11 看到的只是民国·他抵达邮轮时**手腕上突然多了一颗与赛博 S05 开场赛博·她送给赛博·他的那颗一模一样的金色转运珠**、并能完整唱出《蓝点》——这就是"那场场外对谈"留下的全部痕迹（这颗珠子的完整循环来历——陌生访客在 S05 粒子化瞬间承接、亲手留给民国·他——只在 S15 揭穿）。陌生访客的剪影只在 S13a 婚礼/S13b 码头的某个角落短暂消散一次。整段民国剧情让玩家以为是民国他自己想通了。**S14 不揭穿任何真相**——蜡烛熄灭、男主只留下一句「生日快乐，姐姐」就淡化消失。**真相只在 S15（条件性奖励）一次性揭穿**——而 S15 的解锁条件是 **S06a + S13a 双 Good 路径**（即赛博段她的爱意敞亮到让钻戒显形、民国段她敢在权贵面前说出"我陪他承担"）；走其他三条路径的玩家在 S14 蜡烛熄灭那一刻就完结，**永远见不到那封信、永远不被告知三时空真相**——这本身是另一种残念
- **关键叙事原则（信物分时空原则）**：本剧本三件信物**没有任何一件是"现实就有、贯穿三时空"的物件**——
  - **金色转运珠**：起源于**赛博 S05 开场**（**第四轮反馈合并后从 S04 末尾挪到 S05 开场**）赛博·她为他买的辟邪信物（动机："S04 那一夜太险、她希望他下次不要再那么危险"——不是她母亲留给她的、也不是她贴身带着的），赛博 S05 粒子化时由穿越者形态的现实他承接、带到民国留给民国·他；现实段双方手上从未出现
  - **白金钻戒 + 求婚草图**：起源于**现实他**心里那张没说出口的求婚（那幅"开满玫瑰月亮上单膝跪求婚"的画）；赛博段以求婚信物形式仅在 S06a 显形、民国段以白金婚戒形式仅在 S13a 由民国·他亲手戴到民国·她手上、走其他路径永不显形
  - **四叶草铂金耳钉**：起源于**民国 S13a 婚礼前**民国·他亲手送给民国·她；现实段、赛博段、民国 S08–S12 她耳上始终是空的
  - **跨时空"似曾相识"统一原则**：所有"我们好像在哪儿见过"都通过**眼神、笑容、那种"应该一直见到"的少年感、那种说不清的心口酸**来承载，**不靠任何贯穿三时空的实物锚点**。这是本剧本处理时空联结的统一手法，也是 S07 现实回廊里她"摸了摸空空的耳垂、说不清自己以为应该有什么"那个动作的设计依据
- **关键叙事原则（赛博段隐藏伏笔·条件性揭穿）**：赛博·他兜里那枚**白金钻戒**在赛博段主体剧情（S02–S05）中**全程隐藏**——玩家、赛博·她都不知道它存在；它仅在 S06a 结局画面里显形（S06b 永不显形）。其完整真相（"那是现实他想送给你的求婚信物，他要先看到你愿意把爱意敞亮地交出来才敢把它留下"）**只在 S15 条件性奖励里揭穿**——若玩家未走 S06a+S13a 双 Good 路径而无法解锁 S15，则这枚钻戒的真相永远停在"奇异地眼熟"或"她甚至不知道有过它"的层次，不再被点破
- **关键关系反讽（民国段开局）**：民国·她与民国·大小姐**原本是认识的**（社交圈旧友/闺蜜级别的相熟）——这是民国段开局的反讽底色。S08 月光餐厅里玩家代入民国·她、坐在大小姐对面听她幸福地讲述她的"外交官"未婚夫；玩家在那一刻就要承担两份重量——既是大小姐的朋友，又即将成为她未婚夫无法割舍的另一个女人。这份"我们本来认识"的设定让 S10 暴雨裂痕里大小姐的崩溃和 S13a/b 的命运抉择都更刺骨
- **分支密度**：
  - **赛博段（S02–S05）**：**累积爱意制 + S05 关键选择**——S02、S03、S04 每场含若干轻量爱意互动小选项（不切场、仅在场内呈现语气与回应方向；玩家无需感知机制存在），暗中累积"爱意值"；S05 给出一个显式命运选项（关于"救他/陪他 vs 听他/送他完成任务"）作为权重最大的最后一击。**总爱意值 + S05 选择**共同决定结局画面走 S06a（钻戒显形）或 S06b(钻戒不显形）。这与"她渴望爱情但不索求"的人物设定一致——她不被强迫"必须爱多少"，但她爱意敞亮的程度，决定了他是否敢把全部交付给她
  - **民国段（S08–S12）**：**单一命运选项制**——S12 一个显式命运选项决定走 S13a / S13b
  - 两段都为未来"情感值系统"预留接口
- **结局数量**：**1 个基础真终结局 + 1 个条件性奖励真终结局**——
  - **E01 想见你**（基础真终结局）：4 条路径（S06a+S13a / S06a+S13b / S06b+S13a / S06b+S13b）都通向 S14；S14 蜡烛熄灭、男主化作"生日快乐，姐姐"消失即触发 E01。这是大部分玩家会看到的结局，留下未解之谜与未尽的余韵
  - **E02 真·想见你**（条件性奖励真终结局）：仅当玩家走的是 **S06a + S13a 双 Good 路径**时，S14 蜡烛熄灭后会**额外**进入 S15——男主化作一封信，揭穿三时空全部真相（陌生访客=穿越的他、金色转运珠的循环传承"她在每个时空都在送给他保护"、四叶草耳钉"由民国时空里的他完成的他在现实里始终没能亲手给你的那一份赠礼"、《蓝点》的来历、白金钻戒的求婚信物身份、那句私密暗语）+ "如果我们一开始就在现实里相见会怎样"的想象画面长卷。E02 是给"她爱意够浓 + 选择陪他承担"的玩家的最完整告白
  - 段落变体：赛博段、民国段各有 2 个段落变体（S06a/S06b、S13a/S13b）作为路径分流

### 分支树设计原则

> ⚠️ 分支树遵守如下：
> 1. **可达性**：所有 SCENE_ID 从 S01 可达 ✓
> 2. **结局可达**：E01 可被 4 条路径触发（S06a→S07→…→S13a→S14 / S06a→…→S13b→S14 / S06b→…→S13a→S14 / S06b→…→S13b→S14）；E02 仅可被 1 条路径触发（S06a→S07→…→S13a→S14→**S15**）
> 3. **无死胡同**：除 S14（基础结局节点）和 S15（条件性奖励结局节点）外每场都有出口 ✓
> 4. **允许汇合点**：S07、S14 是汇合点（S07 也是赛博 BE 汇回现实的回廊，S14 是民国 BE 汇回现实的终章；S14 既是 E01 的触发节点，也是 S15 的条件性入口）✓
> 5. **共享结局**：4 条路径共享 E01（这是设计而非疏忽——本剧本的核心情感在于"无论你在过去做了什么，今天你能抵达的也只有这一刻"）；只有最完美的那 1 条路径额外解锁 E02
> 6. **每个选项至少有 1 场可感知差异**：赛博段累积爱意 + S05 关键选择导向 S06a / S06b 两个文字截然不同的段落 BE（差异核心：结局画面里那枚白金钻戒**有 / 无**）；S12 的两个显式选项导向 S13a / S13b 两个文字截然不同的段落 BE
> 7. **结局矩阵 ≠ 分支矩阵**：2 个真结局（E01 基础 + E02 条件性奖励）+ 4 个段落变体（S06a/b、S13a/b）
> 8. **赛博段是隐性分支**：玩家在游玩 S02–S05 时**不会感知到累积爱意机制存在**——所有"爱意小选项"在场内仅呈现为对话语气/回应方向的差异（不切场、不弹结局预告）。直到游玩到 S06a 或 S06b 才回头意识到"原来选择是有重量的"。这与"民国段陌生访客身份是叙事盲区"是同一种"伏笔→回收"的潜文本写法
> 9. **S15 是隐藏奖励结局**：解锁条件 = 玩家完整走完 S06a + S13a 双 Good 路径——即赛博段她的爱意敞亮到让钻戒显形（S06a）+ 民国段她敢在权贵面前说"我陪他承担"让婚礼达成（S13a）。S15 不出现在任何场内提示中，玩家在 S14 蜡烛熄灭那一刻不会知道"还有没有"——这与"赛博段隐藏伏笔""民国段叙事盲区"是同一种潜文本设计：**她爱意的浓度，决定她能听见多少他的真心**

## 选择点设计（Choice Points）

> **统一原则（重要）**：所有命运选项都从**她**（女主，玩家代入主体）的视角设计、由她做出。她不"操作他"，她以自己的眼神、口型、低语、央求成为他做出最终行动的"那把钥匙"。这与"她渴望爱情但不索求"的设定一致——她从不主动起头那条频率，但在被爱的瞬间她会替自己说出心里话。

### S05 赛博·守护（长程·命运分叉·**隐性爱意累积制**，由"她"做出）

**情境**：他为送她进轨道飞船已经超频意识到极限，正在化为粒子。她坐在升空舱里隔着舱壁能感觉到他在散——这一刻她必须做出赛博段最后的关键选择。但与一般"显式 A/B → 直接结局"不同：本场选项叠加 S02/S03/S04 三场累积的爱意值，共同决定结局画面走向（玩家无需感知机制存在）。

**S05 关键选择**（权重最大的最后一击）：

- **选项 A：（她）「我不走！」——冒险救他/陪他/抓住他**
  - 表现层：她从准备登舱的姿势里转回来，向他冲去（或隔着舱壁拼命拍打、或喊他名字、或央求他一起走）；她不愿让他独自承担这个代价
  - 爱意权重：**高**（她敢替自己说出"我要他"；这是最直接的爱意外溢）
  - 长期影响：累计在前面的爱意值上，最易触发 S06a（钻戒显形）
- **选项 B：（她）「我听你的，我上船。」——遵从他的安排，让他完成"送她走"这件事**
  - 表现层：她按下了登舱按钮；她明白他已经决定的事不能动摇；她选择信任他给她的最后这条路
  - 爱意权重：**中**（这是另一种深爱——尊重他的牺牲；但她没在他面前敞亮地"要"他）
  - 长期影响：是否触发 S06a 取决于前三场累积值是否已经够高；不够高时落到 S06b

**结局判定**：

- 总爱意值 = S02 累积值 + S03 累积值 + S04 累积值 + S05 选择权重
- 总爱意值 **≥ 阈值** → **S06a 赛博·钻戒之光**（结局画面里求婚信物**显形**——他敢把全部交付给她）
- 总爱意值 **< 阈值** → **S06b 赛博·虚无之相**（结局画面里求婚信物**永不显形**——他没能在最后一刻确认她准备好了，于是把那一切也一起带走）

**隐藏情感值（预留）**：

- `赛博·爱意值`（数值，由 S02–S05 累积）
- `求婚信物显形 = (赛博·爱意值 ≥ 阈值)`
- 阈值的具体设定与每场每选项的权重值由 Phase 3 写作时调校；档案这里只确定机制

**为什么用累积制而不是单一选项**：
- 与"她渴望爱情但不索求"的人物设定一致——她不被强迫"必须爱多少"，但她爱意敞亮的程度，决定了他是否敢把全部交付给她
- 钻戒在赛博段主体剧情中**全程隐藏**（S02–S05 玩家完全不知道它存在），仅在 S06a 结局画面才显形——这是赛博段的隐藏伏笔，与"民国段陌生访客身份是叙事盲区"是同一种潜文本写法
- 玩家二周目调整选择时会恍然大悟"原来选择是有重量的"——这与 S15（条件性奖励，仅 S06a + S13a 双 Good 路径解锁）那封信里揭穿"那枚钻戒是现实他想送你的求婚信物"形成双重回收，并驱动玩家追求最完美路径

### S12 民国·抉择（长程·命运分叉，由"她"做出）

**情境**：S11 邮轮上他已经唱起《蓝点》、把"我要和她在一起"这件事推到了无法回头的地步。第二天/几天后，男主和女主**一起站到了权贵面前**——权贵正面出场，他不抬高音量，却把每一句话都砸成了铡刀。他给出二选一的威胁——要么"身败名裂"，要么"男主主动离开"。男主已经准备替自己回答，但**她**抢在他开口之前——她要替自己、也替他做出这个选择。她坐在权贵的客厅里，掌心攥得发白，抬眼隔着权贵的烟看了一眼站在她身侧的他、又把目光收回来；她知道她说出口的下一句话，会决定他这一世接下来的全部。

- **选项 A：（她）「我陪他承担。」——选择身败名裂（→ S13a 民国·婚礼凋零）**
  - 即时差异：她对权贵开口，话里没有半个高音；她说她愿意和他一起承担所有的身败名裂——她不要他保住的体面，她要他这个人。男主在她身后那一秒红了眼眶；他握住她的手；他们当着权贵的面没有说什么大话，但走出那间客厅时两个人的步子已经合上了。**结果**：迟到的、不被祝福的婚礼达成；婚礼前他亲手把那对**四叶草铂金耳钉**戴到她耳上（民国段唯一她受赠的信物起源点）；婚礼上他亲手为她戴上那枚**白金婚戒**（=赛博段那枚求婚信物，跨时空回收）；婚礼上远处那位陌生访客慢慢褪色消失
  - 长期影响：玩家记得的是"那一刻她终于敢说出口、他终于敢为她抛下一切、终于敢把那对耳钉戴到她耳上"——遗憾里有甜
  - 隐藏情感值（预留）：`民国选择=承担`、`婚礼达成=true`、`白金戒指戴出=true`、`四叶草耳钉戴上=true`
- **选项 B：（她）「让他走。」——让男主主动离开（→ S13b 民国·邮轮孤帆）**
  - 即时差异：她对权贵开口，声音同样克制；她说她愿意——但她要的是男主能够保全自己的前途、不和她一起被这座城碾碎。她不替自己求情，她替他求一条活路。男主在她身后没说话——他知道她在替他做出他自己永远做不出的那个决定。**结果**：男主被迫离开，远赴他乡；码头送别；那枚**白金钻戒**被他默默留在了那只装信的木匣最深处，**没能戴到她手上**；那对本来要在婚礼前送给她的**四叶草铂金耳钉**也一同停留在他没能交出去的角落（**走 S13b 路径的玩家在这一世里始终见不到那枚戒指、也始终见不到那对耳钉**）；码头另一端那位陌生访客在风里慢慢消散；他在船舷处隔海向她单膝跪下了一秒，没人看得见
  - 长期影响：玩家记得的是"她终于敢替自己做主一次、他没能站在她身边却至少保住了他这个人"——遗憾里有刺
  - 隐藏情感值（预留）：`民国选择=放手`、`婚礼达成=false`、`白金戒指戴出=false`、`四叶草耳钉戴上=false`

> **重要原则 1**：S12 / S13a/b 中所有的决定、台词、动作都是民国·他**自己**做出的（他在 S11 一夜对谈后已经想通了）。陌生访客只是在角落见证，从不替民国·他开口；她也不"操作他"——她只是在他已经想通的基础上替自己说出最后一句心里话，他读懂后**自决**执行——这是机制的核心边界。

> **重要原则 2（叙事盲区·更彻底版）**：陌生访客与民国·他的整场对谈**完全发生在剧本之外、镜头之外**（在 S10 暴雨之后、S11 邮轮密约之前的某个夜里）——剧本从不分配场次给它，玩家也不会从任何视角看到对谈内容。玩家在 S11 邮轮密约里看到的只是民国·他抵达时**手腕上多了一颗与赛博 S05 开场那颗一模一样的金色转运珠**、并能完整唱出《蓝点》——这是这场"场外对谈"留下的全部痕迹（陌生访客在赛博 S05 粒子化瞬间承接了那颗珠子、亲手留给民国·他的完整循环只在 S15 揭穿）。陌生访客本人在 S13a / S13b 也只以"角落里慢慢消散的剪影"短暂出现一次。这个谜底**只在 S15 条件性奖励里揭穿**——若玩家未走 S06a+S13a 双 Good 路径而无法解锁 S15，则陌生访客的真实身份永远停留在"角落里那个眼熟的、不知是谁的剪影"，不再被点破。

> **重要说明 1**：S05 与 S12 的两个选项都以"她替自己做出了什么样的告白"为分流口，没有"对/错"——所有路径最终都汇于 E01-想见你（基础真终结局）。这种设计恰好对应主题："无论他在多少个时空里挣扎着想抵达她，最终能确切抵达她的，仍然只有现实中那根蜡烛被吹灭的瞬间。"

> **重要说明 2（隐藏奖励结局 E02 的解锁机制）**：S05 与 S12 的两次选择**联合**决定 S14 之后是否解锁 S15——
> - **S06a + S13a**（赛博段她的爱意敞亮到让钻戒显形 + 民国段她敢说"我陪他承担"让婚礼达成）→ **解锁 S15 真告白与想象未来 → E02 真·想见你**
> - 其他三条路径（S06a+S13b / S06b+S13a / S06b+S13b）→ S14 蜡烛熄灭后游戏完结于 E01，**永远见不到那封信**
> - 这是与"赛博段隐藏伏笔"同构的潜文本设计：**她爱意的浓度，决定她能听见多少他的真心**——只有"在赛博里愿意陪他、在民国里敢替他承担"的她，才能让现实的他敢把全部交出来
> - 玩家在场内不会被任何提示告知"S15 存在"——这是给最完美路径的隐藏奖励，鼓励二周目调整选择重玩

## 全剧本悬念线

- **主线悬念（长弧·条件性揭晓）**：屏幕外那个"他"为什么不能在今天到场？为什么"他"愿意付出意识透支与亲身穿越的代价反复抵达她？玩家会越玩越意识到"现实里的他"和"她"似乎从未真实见过——**S14 不正面揭晓**（蜡烛熄灭、男主只留下一句"生日快乐，姐姐"）；**只有走 S06a + S13a 双 Good 路径的玩家在 S15 那封信里听到完整答案**（"我们至今没真实相见 / 我每次穿越都是为了多见你一次 / 但我最想的还是与现实中的你相见"）；其他路径玩家永远停留在"屏幕外那个他到底是谁、为什么不来"的留白里——这本身是另一种残念
- **现实回廊悬念（短弧·条件性揭晓）**：S07 是赛博 BE 之后被拉回现实的过渡场——她为什么会带着"刚才好像经历了什么"的余韵回到蛋糕前？她许下的第二个愿望是什么？她不会说出口，但她许愿前手指会下意识抬起来摸一下自己的右耳耳垂——**那里空空的、却让她说不清自己以为应该有什么**（这是赛博段亲手把金珠子系到他手腕上又看着它随他粒子化的失落痕迹——S15 揭穿时玩家会突然想起来"原来你那一刻摸的，是你以为应该有的、他后来在民国时空里才能戴到你耳上的那对四叶草耳钉的位置"）。**附**：S07 中他那句「**姐姐，你怎么了？好像刚才有那么一秒，失了神。**」语气是关心的、但藏着一种"他好像知道"的克制——这是 **S15** 真告白时玩家会突然回想起来的关键句（"原来他从头到尾都知道我经历了什么"）；走非 S15 路径的玩家在 S14 蜡烛熄灭那一刻就完结，这层伏笔永远停在"他好像知道但说不清"的层次
- **赛博支线悬念（中弧·条件性揭晓）**：为什么他偶尔会出现奇怪征兆，甚至喃喃念出一句诗的碎片（如 S04 那句"轮回里……我总记得你眼睛……"）？为什么改装车启动那一刻他突然像分不清"我是不是只是在替谁活完这一段"？答案在 S04→S05 部分揭开（其完整真相——"那是现实他的意识在入侵"——**只在 S15 条件性奖励里揭穿**）。**注 1（金色转运珠的赛博归宿悬念）**：赛博·她在 S05 开场（**第四轮反馈合并后从 S04 末尾挪到 S05 开场**）亲手把她为他买的金色转运珠系到赛博·他手腕上，他粒子化时这颗珠子的去向在赛博段不被回答（**S15 揭穿**：那一刻它跟着穿越者形态的现实他去了民国）。**注 2（白金钻戒）**：那枚白金钻戒在主体剧情（S02–S05）中**全程隐藏**——它不作为悬念线条目暴露给玩家，仅在 S06a 高爱意结局画面才显形；走 S06b 路径的玩家在赛博段完全不知道有过这枚信物，要在 S15 那封信里才被告知"原来他兜里一直藏着想送你的求婚信物"——但走 S06b+任意民国路径的玩家**无法解锁 S15**，这层揭穿对他们永久封存
- **民国关系反讽（中弧）**：女主与大小姐**原本是认识的**——这是民国段开局的反讽底色，会在 S10 暴雨裂痕里大小姐当面崩溃时反弹至最痛的一刻
- **民国支线悬念（中弧·条件性揭晓）**：民国·他为什么会在 S10 暴雨之后、S11 邮轮抵达时突然定下心来？为什么他手腕上原本没有那颗金色珠子，S11 抵达邮轮时却已经多了一颗**与赛博 S05 开场那颗一模一样的金色转运珠**、并贯穿 S12/S13？为什么 S13a 婚礼/S13b 码头总有一个眼熟的陌生人在远处的某个角落慢慢褪色消失？为什么民国·他突然就会唱《蓝点》了？——这一切的解释（陌生访客=穿越来的现实他、对谈完全发生在剧本之外、那颗金珠子是陌生访客在赛博 S05 粒子化瞬间承接、亲手留给民国·他的——意味着"她在每个时空都在送给他保护"、《蓝点》是从对谈中带回来的承诺）**只在 S15 条件性奖励里一次性揭穿**（**这是本剧本最大的伏笔**）；走非 S15 路径的玩家——包括走了 S13a 但赛博段没走 S06a 的玩家——这些谜底永远封存
- **民国"未烧的信"伏笔（短弧）→ S10 直接回收**：S09 末尾男主舍不得烧、把木匣重新藏好——**S10 暴雨裂痕直接回收**：那只木匣（书信 + 一张她的照片）被大小姐找到，成为实锤导火线；大小姐拿着它当面对质崩溃，并把它送到了权贵那里。这个伏笔在民国段中段就完成回收（不再延后到 S12/S13）。"他舍不得烧的那一切，最终成了一把刀，由他爱过的人转交到了她的丈夫手上"——这是民国段最沉的因果之一
- **跨时空意象悬念（短弧·条件性揭晓）**：
  - **《没有人能比我们更接近对方》**——仅作赛博段一次性背景音（不作通讯频率、不作相认信号、无具体歌词锚点）
  - **《蓝点》**——民国独有的承诺之歌；在 S11 由民国·他独自唱起作为对女主的承诺（来历谜底封存到 S15）
  - **白金钻戒 + 求婚草图**——现实他想送给她、却还没送出去的求婚信物；草图内容是**一颗开满玫瑰的月亮上他穿西装、向穿白色礼服的她单膝跪地求婚**（这其实是现实他自己画的那幅画）。
    - **赛博段**：S02–S05 主体剧情中**全程隐藏**（玩家完全不知道它存在），仅在 S06a 高爱意结局画面里第一次显形；并在那一刻以一段**"不属于这一世的闪回"**短暂涌进赛博·她的意识里（她说不出那是谁、那是哪里，只觉得心口酸得厉害）。S06b 路径下钻戒、草图、闪回画面**全部不显形**
    - **民国段·S13a 婚戒回收（关键跨时空回收）**：走 S12 选 A 路径时，民国·他亲手为民国·她戴上的那枚**白金婚戒**——**正是赛博段那枚白金钻戒**（同样的白金质感、同样的切割与反光）。走 S06a 路径的玩家会立刻认出来（前置回收快感）；走 S06b 路径的玩家会觉得这枚戒指奇异地眼熟却说不上来（悬念加深）
    - **民国段·S13b 不显形**：走 S12 选 B 路径时，那枚白金钻戒被民国·他默默留在木匣最深处，**从未戴到她手上**——走 S13b 路径的玩家在这一世里始终见不到那枚戒指
    - **S15 一次性揭穿全部真相（仅 S06a+S13a 路径解锁）**："那幅画/那枚戒指/那个开满玫瑰的月亮"都是现实他想送你的求婚信物，是他没说出口的那一句"嫁给我"——并在 S15 想象画面长卷里再次出现"他亲手把那枚白金钻戒戴到她手上"的画面，与 S06a 闪回、S13a 婚戒形成**三重回收**。其他路径玩家永远见不到这层揭穿
  - **四叶草铂金耳钉（仅民国 S13a 路径出现）**——民国·他在 S13a 婚礼前送给民国·她的礼物（含义"四叶草=我希望你余下的日子里都有人替你扛走运气这件事"）。
    - **现实段**：她从未收到、耳上始终是空的；S07 现实回廊里她下意识抬手摸了摸自己空空的耳垂、说不清自己以为那里应该有什么——这是赛博 BE 之后留下的、她无法言说的失落痕迹（其完整缘由要到 S15 才揭穿）
    - **赛博段**：她耳上始终是空的；不出现这件信物
    - **民国段·S08–S12**：她耳上始终是空的——她还是大小姐的旧友/还在风口浪尖的关系里，他还没能力把这对耳钉戴到她耳上
    - **民国段·S13a**：婚礼前他亲手戴到她耳上；婚礼上她戴着走进了那场不被祝福的婚礼（**这一对耳钉的存在本身就是民国段 Good 路径独有的"他终于敢把全部交付给你"的实物证据**）
    - **民国段·S13b**：她永远不会收到这对耳钉——这一世他没能走到能把它戴到她耳上的那一天（与那枚白金钻戒同等待遇，永远停在他没能交出去的角落）
    - **S15 揭穿（条件性·仅 S06a+S13a 路径解锁）**：现实他在那封信里告诉她——这对耳钉的设计灵感、那句"四叶草是我希望有人替你扛走运气"的话、甚至民国·他递盒子时的那个手势，都是他的——是他借由民国时空里的他完成的、他在现实里始终没能亲手给她的那一份赠礼
  - **金色转运珠（赛博段起源 → 民国段经由穿越承接）**——
    - **起源·赛博 S05 开场**（**第四轮反馈合并后从 S04 末尾挪到 S05 开场**）：赛博·她在 S05 一见面时把她为他特意买的金色转运珠（动机："S04 那一夜太险、她希望他下次不要再那么危险"），亲手系到赛博·他右手腕上——她借这颗珠子说"听说这种珠子能辟邪、能让人不出事"+"……我希望——你下次不要那么危险"（潜台词："答应我别死"）；起源动机不再是"母亲留给她、贴身带着的护身符"、而是"她为他特意买的"——更克制、更直接、更符合"她担心他下一次再这样冲会回不来"的承接逻辑
    - **赛博段·S02–S04 全程**（**第四轮反馈合并后扩展**）：赛博·他手腕上**没有**这颗珠子（4.1–4.5 全程男主右手腕都是空的）
    - **赛博段·S05 开场起·一直戴**：赛博·他从 S05 开场系上之后一直戴在右手腕上，直到 S05 化为粒子的最后一刻；粒子化时这颗珠子的去向在赛博段不被回答，留白处理
    - **现实段**：现实他、现实她**手上从未戴过这颗珠子**——这件信物从不出现在现实的任何场次里
    - **民国段·S08–S10**：民国·他手腕上**没有**这颗珠子
    - **民国段·S11**：民国·他抵达邮轮时手腕上**突然多了这颗珠子**——一颗与赛博 S05 开场那颗一模一样的金色转运珠（玩家在这一刻会"咦"一下；走 S06a 路径的玩家会更强烈地觉得"这颗珠子我见过"，但剧本不点破）
    - **民国段·S13a/S13b**：民国·他都一直戴着这颗珠子（婚礼上 / 邮轮上），直到这一世结束
    - **S15 揭穿（条件性·仅 S06a+S13a 路径解锁）**：陌生访客（=穿越者形态的现实他）在 S05 赛博·他粒子化的瞬间承接了这颗珠子，并在 S10 之后的场外对谈里亲手把它留给了民国·他——这意味着**这颗珠子是"她"在每个时空都在送给他的同一份保护**（赛博的她直接给他、民国的她借由现实他的手间接给他）；与"他在每个时空都在抵达她"形成首尾互文
  - **那句私密暗语「轮回里，我总记得你眼睛，一次又一次爱上你，直到白首不分离」**——他们之间最深的私密信物；由"他"以变体方式说出（女主不主动起头）；**只在 S15 那封信末尾完整收束**（**最关键回收节点·条件性**）；赛博段可作意识入侵征兆之一出现碎片（如 S04 那句"轮回里……我总记得你眼睛……"），民国段 S11 不出现、其他位置可由 Phase 3 写作时酌情安排；走非 S15 路径的玩家永远听不到这句话的完整版
- **每个结局对应的揭秘程度**：
  - **E01-想见你（基础真终结局，4 条路径都触发）**：S14 蜡烛熄灭、男主化作"生日快乐，姐姐"消失。**所有真相都不揭穿**——他屏幕外的身份、他与她从未真实相见、陌生访客身份、金珠子的传承、《蓝点》的来历、白金钻戒的求婚信物身份、那句私密暗语的完整版……全部封存。玩家带着"他到底是谁/我到底经历了什么"的余韵走出剧本——这是一种刻意保留的"未尽之憾"
  - **E02-真·想见你（条件性奖励真终结局，仅 S06a+S13a 路径触发）**：S15 那封信会一次性揭开"屏幕外的他"的全部底牌——"我们至今没真实相见"这件事、"陌生访客就是穿越来的我"、"民国他手腕上那颗金珠子是我亲手留给他的"、"《蓝点》是我从对谈中带回来的承诺"、"那枚白金钻戒是我想送你的求婚信物"、"那幅开满玫瑰月亮上的画就是我"、"每次你许愿我也跟着许想见你然后就穿越了"，以那句诗作为最终收束；并以"如果我们一开始就在现实里相见"的想象画面长卷收尾——这是给最完美路径的最完整告白
