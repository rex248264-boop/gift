# S15 尾章·告白

> **上游来源**：S14（仅 S06a + S13a 双 Good 路径触发·玩家在场内不会被任何提示告知 S15 存在）
> **下游出口**：[结局: E02-真·想见你（条件性奖励真终结局）]
> **本场画面数**：5
> **本场总字数预算**：约 750–1000 字（真告白长卷类场次·可超常规上限）
> **本场估算游玩时长**：约 5–8 分钟
> **核心事件提要（来自 01-大纲.md）**：S14 蜡烛熄灭、屏幕黑暗后，画面里慢慢浮现出一封信——现实他亲手写给她的告白情书。信件一次性揭穿三时空全部真相：赛博意识入侵、民国亲身穿越、金珠子循环传承、四叶草铂金耳钉的转手赠礼、白金婚戒是求婚信物、《蓝点》的来历、穿越动机（每次她许愿时他也许"想见你"然后就穿越了）、私密暗语完整版。信尽，画面里无声流过"如果我们一开始就在现实里相见"的想象画面长卷。最后定格一行字——「这一次，我来找你。」
>
> **本场潜文本克制·零点破写法自检**：本场是全剧本唯一一次正面揭穿所有真相的场次——S01–S14 全程克制未说的每一处伏笔，在此一次性回收。所有揭穿必须做到"先锚定玩家在前面看到的那一幕，再点破真相"——让玩家在听到真相的瞬间自己完成回忆与对位，不靠重复叙述。
>
> **本场含 0 个累积爱意小选项 + 0 个长程命运分叉**（条件性奖励结局·无分叉）。

### 画面描述

**场景**【特写·信纸满屏】：信纸铺满整个画面；从第一行字开始，随玩家阅读节奏向上缓缓滚动；字迹在某几处按得稍重，像是写到这里停了一下才继续

**人物**：（无）

**微动效**：信纸上某道折痕在光里极轻地起伏，像有人捧着它还没放下；墨迹最深处有一点点微光

### 对话

——【信件展示·玩家随节奏阅读】——

> 「亲爱的姐姐，
>
> 生日快乐。
>
> 也许你会疑惑，这一切究竟是什么。其实我也不知道，我只知道的，只是那天
>
> 关于赛博之城那个偶尔目光空白、从牙缝里漏话的男孩——那不只是他一个人。是我的意识叠在他身上，我在那一头，透过他的眼睛看你。S04那夜他说的"轮回里……我总记得你眼睛……"——是我，不是他。
>
> 民国婚礼角落里那个陌生人——也是我。
>
> 暴雨那夜之后，我找到了他。他那时候还没想通，迷茫，怕。我们谈了一整夜。我把《蓝点》教给他，让他记住了。
>
> 然后说说那颗珠子。那颗金色转运珠，是你在赛博世界里亲手为他买的——珠面圆弧纹路，代表智慧；你说，希望他清醒、不迷。他粒子化时我把它带走了，在民国把它交给了他，让他戴上。
>
> 这意味着——你在每一个不允许我们相见的世界里，都在把同一份保护给他。
>
> 你只是不知道。」

### 转场

文字向上滚完，信纸下半段浮出，余下的字在折痕之下 → 切下一帧（Frame 15.3）

**微动效**：那道最深的折痕在这一段正好穿过信纸中部；墨迹在折痕处有一丝极浅的洇开，像写这封信时有水落在上面

### 对话

——【信件展示·玩家随节奏阅读·续】——

>

>

>

## Frame 15.4 · 想象画面长卷

### 画面描述

**场景**【第三人称·连续长卷·无对白·无配音】：画面里无声地流过一组画面——他想象中，如果他们一开始就在现实里相见，会有的种种：

某个咖啡馆的某天下午，他走进来，隔着几张桌子一眼认出了她，停了一下，然后走过去；

第一次他亲手把那对四叶草铂金耳钉戴到她耳上——在现实里，不借由任何时空里的他，就是他，就是她，就是那个下午；

他把那颗金色转运珠系到她手腕上——这一次轮到他给她保护，和赛博那夜她系给他的方向相反；

一颗开满玫瑰的月亮上，他穿着合身的深蓝西装，单膝跪在她面前，手里是那枚白金钻戒，他把它戴上了她的手；

某个清晨，他侧过头，看着她睡着时的侧脸，停了很久，没有说话；

白发苍苍，仍然并肩坐在某个阳台上，他的手覆在她的手上，像压住了什么，也像什么都不用再说了

**人物**：（每组画面里均有他与她；面目不清晰，只看得见姿态与相对位置）

**微动效**：每组画面无声，有颜色，像一幅一幅被翻过的旧照片；每两幅之间是极轻的透明渐变；没有字幕，没有配音，只有画面

### 转场

长卷流完，最后一幅定格——他的手覆在她的手上，两人并肩；画面极慢地推近到那两只手 → 黑暗 0.3s → 切下一帧（Frame 15.5）

## 精简记录

① **本场 5 帧结构**：15.1 黑暗·信浮现（全黑·信纸在暗里展开·旁白"他一直都知道"）→ 15.2 信·上（揭穿赛博意识入侵 + 民国亲身穿越 + 金珠子循环传承）→ 15.3 信·下（揭穿四叶草耳钉转手赠礼 + 白金婚戒求婚信物身份 + 穿越动机 + 私密暗语完整版）→ 15.4 想象画面长卷（无对白·无配音·6 组画面·初次见面/耳钉现实完成/转运珠方向互文/求婚戒完成/清晨侧脸/白头并肩）→ 15.5 这一次，我来找你（全黑·一行字·结局）。

② **信件写法原则**：信以"你"指代姐姐、以"他"指代赛博/民国时空里的男主；现实他以"我"自称。揭穿顺序：赛博意识入侵 → 民国穿越+《蓝点》 → 金珠子循环传承 → 四叶草耳钉转手赠礼 → 白金戒指求婚信物身份 → 穿越动机 → 私密暗语。每段揭穿都先给出"玩家在前面看到的那一幕"作为锚点（"S04那夜那句话/民国角落里的陌生人/S07那个空空的耳垂/驾驶舱里拾起来的那枚"），然后直接点破，不绕。**信件最重要的一段是耳钉揭穿**——"你在S07摸了摸空空的耳垂"这一句是所有玩家都走过的路径、是最普遍的伏笔回收锚点，情感冲击力最高。

③ **私密暗语完整版落地**：「轮回里，我总记得你眼睛。一次又一次爱上你，直到白首不分离。」——作为信末收束，与 S04 Frame 4.4 诗碎"姐姐——轮回里——我总记得你眼睛——"+ S05 Frame 5.4 诗碎"姐姐——一次又一次——"形成**三重回收**（碎片一 + 碎片二 + S15 完整版）。完整版在信件正文里以独立两行呈现，不嵌入段落，是信的情感高峰。

④ **想象画面长卷的 6 组画面设计**：初次见面（现实里第一次真实相遇）→ 他亲手戴耳钉（填补 S07 空耳垂失落）→ 他把转运珠系给她（与赛博 S05 她系给他形成首尾互文·方向互换）→ 他单膝求婚戴上白金钻戒（与 S06a 闪回·S13a 婚戒形成三重回收）→ 清晨侧脸（最安静的一帧）→ 白发仍并肩（"直到白首不分离"的视觉落地）。长卷无对白、无配音，靠画面+音乐承载，是整本剧本节奏最慢、情感密度最高的一段。

⑤ **"这一次，我来找你"的写法**：全黑背景、一行字、无旁白、无任何其他元素——字本身就是全部重量。与 S14 极简版"生日快乐，姐姐"形成首尾互文：E01 是他留下一句告别就消失，E02 是他留下"这一次，我来找你"——不是道别，是宣言。

⑥ **跨场互文锚点全收束**：S01"他用深蓝西装坐在桌对面"→ S15 想象画面里他穿"深蓝西装单膝跪求婚"（闪回与现实完成的三重对位）；S02 Frame 2.2 选 B 路径"她的指尖按到空空的耳垂上"→ S07"她摸了摸空空的耳垂"→ S15 信里"那就是那对耳钉本来应该在的位置"（三场跨时空闭环）；S04 诗碎"轮回里……我总记得你眼睛"+ S05 诗碎"一次又一次——"→ S15 完整版（碎片×2 + 完整版·三重回收）；S05 开场"赛博·她把转运珠系给他"→ S15 想象画面里"他把转运珠系给她"（首尾互文·保护方向互换）；S06a "驾驶舱里那枚白金钻戒"→ S13a "婚礼上那枚白金婚戒"→ S15 信里"那是求婚戒"+ 想象画面里"他单膝求婚"（三重回收）。

⑦ **本场字数估算（玩家可读单条路径）约 760 字**——信件两部分约 500 字，简洁而不省略任何关键揭穿；想象画面长卷以画面描述承载（不靠文字密度承载，靠画面本身）；整体在 750–1000 预算内。情感色调：温暖，完整，是所有路径里情感密度最高的终点。
