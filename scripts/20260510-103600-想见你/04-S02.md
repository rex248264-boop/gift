# S02 赛博·霓虹初见

> **上游来源**：S01 Frame 1.3 末尾富过渡（霓虹光晕白闪 0.3s）
> **下游出口**：跳转 → S03
> **本场画面数**：5
> **本场总字数预算**：约 300–450 字（玩家可读：旁白 + 对话 + 选项分支）—— ⚠️ **本场实际玩家可读字数 ~780**（单条路径），超预算约 70%；超出原因记录见篇末"精简记录"⑨
> **本场估算游玩时长**：约 2–3.5 分钟
> **核心事件提要（来自 01-大纲.md）**：S01 末尾花房霓虹化崩塌、被霓虹重新拼起——你（赛博·她，玩家代入）从赛博重组的小桌前**坐着醒来**，桌上是花房带过来的香槟杯与一束没被吹灭、被重组成酒吧小烛灯的烛火；这是赛博之城地下一家**安静的酒吧**（霓虹收得极克制、暖橙灯下、窗外是冷紫色霓虹细雨）。角落里的旧式立体收音机正循环播放一首老歌《没有人能比我们更接近对方》（仅作背景音、不出现具体歌词锚点）。**远处吧台另一侧或另一张靠窗的小桌前坐着他**——你与他之间隔着三五张暖橙灯下的空桌子；他在副歌处无意识跟着哼了一句尾音、你不自觉屏住呼吸；两人在同一个尾音里对望（你的目光"熟悉里带着陌生、陌生里又压着熟悉"）→ **你做出"跟不跟哼"的选择 → 下一帧承载他抬头之后稳稳看着你的反应**（A 路径目光直接落进你眼睛 / B 路径目光落在你停在右耳耳垂上的指尖上）→ **他主动起身、把酒杯放下、走过那几张桌子的距离、在你对面坐下**开始第一次对话（**对话围绕这首歌的歌词展开**——「你也喜欢听？」 / 「我很喜欢这首歌的歌词」 / 「写得很浪漫」 / 「……你说——梦境的边缘、星河的中央，会是什么？」 / 「……我从前以为，那是没人能去的地方」 / 「……今晚我才想，也许那是有人在那一头等着另一个人去找他的地方」——几句之后他抬手指了指头顶天窗 → 进入 Frame 2.5）。结尾他半玩笑半认真地问你——「……愿不愿意——跟我一起去那上面？」——把"星河的中央"具象化为头顶天窗里那颗近得像伸手就能碰到、却其实没人真的开过去过的月球（**改装车在 S02 不正面登场，要到 S03 才进入画面**）。本场含 2 个累积爱意小选项（不切场）。
>
> **本场信物可见性自检**：金色转运珠 ✗（S04 末尾才起源——男主手腕没东西）；白金钻戒 + 求婚草图 ✗（仅 S06a 显形——男主兜里那枚在 S02 全程隐藏，剧本不提、不展示）；四叶草铂金耳钉 ✗（S13a 起源——女主耳上是空的；Frame 2.2 选项 B 路径含"指尖按到右耳耳垂、那里空空的、你那里应该有一颗东西也跟着轻轻颤了一下"动作合规——这是赛博世界里她对自己耳垂位置的一个无意识小动作；他随后被她这一指尖唤住、目光落在那一截指尖上像看见了某样本来应该在那里却没在那里的东西——这是现实他记忆里那对四叶草耳钉的隐性投射，与 S07 现实回廊"摸空耳垂"伏笔形成隐性互文，但 S02 不点破）。
>
> **本场画面格式自检**：每帧四块齐全（画面描述 → 背景旁白·按需 → 对话·含选择型对话 → 转场）；画面描述仅 3 大子类（场景 / 人物 / 微动效），视角作为「场景」标签；2.1【第三人称】建场——你坐在酒吧靠窗的小桌前、远景看见同样坐着的他、承接 S01 烛光餐桌的"坐姿镜像"+ 香槟杯与烛灯的视觉传承；2.2【FPV·你的视角】副歌尾音 + "熟悉又陌生"的目光 + 跟不跟哼小选项（选项内只承载"她的动作 + 他左手指尖的微反应"，不承载"他抬头看你"的动态）；**2.3【FPV·你的视角】"他已经看到你"的目光定格画面**——画面状态是他抬完头之后稳稳看着你的那一秒（不是"抬头中"的动态过程）；对话块按 Frame 2.2 选项 A/B 分支呈现"他看你的方式"差异（这是合法的"延续上一帧选择的反应分支"用法、仍然不切场、汇合到 Frame 2.4）；2.4【FPV·你的视角】**他主动走过来在你对面坐下**、对话围绕这首歌的歌词展开、几句之后他抬手指头顶天窗；2.5【第三人称】两人对坐桌前、邀约「跟我一起去那上面？」+ 三选项 + 共同后置；2.1/2.2 有旁白、**2.3/2.4/2.5 无旁白**（2.4 删除旁白后调性更克制——把"安静"感全部交给对话本身与微动效承载）；S02 → S03 是同一时空内（赛博段内）简单切换、不用富过渡；2.5 末尾画面淡出 → S03 Frame 3.1（车在 S03 才正面登场）。详见 `interactive-game-scene-format.mdc` §2.1–§2.4。
>
> **本场人物档案合规自检**：**男主在 S02 全程不叫"姐姐"**——"姐姐"这个称呼是现实他意识入侵更明显之后（S04 征兆爆发起）才会无意识地从赛博·他口中冒出来的征兆之一；S02 此刻入侵刚刚开始、还停留在赛博·他眼里那一闪而过的"心口酸"的感觉里、不到口头层；男主标志告白句"我好想你"S02 也不出现（S04 之后高情绪点才出现）；女主害羞用动作（耳尖泛红 / 低头 / 摸空耳垂 / 顺头发到耳后 / 抿到唇里）而非"呀……"；女主不主动起头哼歌——Frame 2.2 选项 A 是"他先哼、她跟着无声哼半个音"，符合"她接收频率不主动起头"原则；私密暗语诗 S02 不出现碎片（S04 才出现"轮回里……"碎片）——但 Frame 2.4 男主"梦境的边缘、星河的中央"那一段是他自己的浪漫提问、不是私密暗语诗，灵感来自这首歌的歌词氛围、不算违规；**男主主动**——Frame 2.4 是他从他那一头主动起身走过来在你对面坐下、并主动抛出"梦境的边缘、星河的中央"这个浪漫提问，符合男主"温柔、热情、直接、不让她猜"的性格内核（女主从不主动起头那条频率，但她坐着等他过来、听他抛出问题时仍是大方而娴静的，用"心跳轻轻漏了一拍"+"抿到唇里"+"心口酸"承载她的接收）。
>
> **本场意识入侵的极轻微痕迹（S04 征兆爆发的铺垫）**：Frame 2.3 选项 A 路径里他目光直接落进你眼睛那一秒"眼里有一种你抓不住、却让你心口又痠了一下的东西"——这是现实他意识刚刚叠加上来的瞬间感受、赛博·他自己也说不清；Frame 2.3 选项 B 路径里他被你按到右耳耳垂的指尖唤住、目光落在你那一截指尖上像看见了某样本来应该在那里却没在那里的东西——这是现实他记忆里那对四叶草耳钉的隐性投射（玩家在 S02 完全感受不到这层、要等到 S15 揭穿时才会回想起来"原来他那一刻看见的，是我应该在现实里就拥有的那对耳钉"）。Frame 2.4 男主那段"梦境的边缘、星河的中央——也许那是有人在那一头等着另一个人去找他的地方"也是意识入侵的极轻微痕迹之一——这句话表面是浪漫提问、底下藏着"我在等你来找我"的自指（现实他借赛博·他之口说出来的、玩家在 S02 同样感受不到这层、要到 S15 才能回想起来）。
>
> **本场两个累积爱意锚点（不切场，玩家无需感知机制存在）**：
>
> - **Frame 2.2 跟不跟哼（反应在 Frame 2.3 呈现）**：A 她跟着他无声哼半个音 → 他目光直接落进你眼睛、心口酸（高爱意） / B 她没出声、可她目光没挪开、右手指尖按到自己的右耳耳垂上、心里浮起"他哼出尾音那一刻、你那里应该有一颗东西也跟着轻轻颤了一下"的感应 → 他目光落在你按耳垂的指尖上、像看见了某样本来应该在那里却没在那里的东西（中上爱意——B 路径不再是冷淡的"挪开目光"，而是另一种形式的"接住他"）
> - **Frame 2.5 回答语气**：A 「……那我跟你一起去」（高爱意） / B 「……为什么是我？」（中爱意） / C 沉默不答、目光在他与天窗之间挪（低爱意）

## Frame 2.1 · 安静酒吧

### 画面描述

**场景**【第三人称】：赛博之城地下某条小巷里的一间安静酒吧——不是那种喧闹的霓虹酒馆，是把霓虹都收得极克制的小酒吧；低悬的暖橙色玻璃灯罩一只一只挂在每一张桌的上方、墙上嵌着几道冷紫色霓虹细线作为分隔；空气里漂着旧木头、酒、和一丁点电流的味道；窗外是冷紫色的霓虹细雨，但窗内是干燥温暖的;角落里立着一台旧式立体收音机，正在循环播放一首老歌——人声轻得像有人在隔了几张桌子的地方哼着这首歌
**人物**：

- 中景前：你（赛博·她，玩家代入），坐在靠窗的一张小卡座前；身上是从花房带过来、被霓虹重组成的金属质感长裙——肩线柔和、腰身利落；耳上空空、手腕没戴东西；桌上是一只刚被你抿了一口的香槟杯（**S01 烛光餐桌带过来的视觉传承**）和一只点着小火苗的金属烛灯（**S01 那束没被吹灭的烛火被重组成的赛博版本**）；目光抬起、停在角落那台收音机上
- 远景中：他（赛博·他）的远景剪影——也坐着，在距你三五张桌子远的吧台另一侧/另一张靠窗的小桌前；只看得见他穿一件有冷光线条的雨衣的侧影；他的脸还看不清；右手腕上没有任何东西
**微动效**：收音机里那首老歌的副歌起声那一拍，墙上嵌着的某道冷紫色霓虹细线极轻地闪了一下；你桌上那只小烛灯的火苗轻轻颤一下；远处他那一桌的暖橙灯隔着烟与酒气一明一暗

### 背景旁白

> 2177年
> 5月12日
> 赛博-月之成
> 城市的中央——
> 有一条直耸入云的月球轨道——
> 据说那里是就是天堂。

【画面切换：月球轨道】

> 而你——
> 从一间酒吧中醒来——
> 这个时代的记忆正在缓慢复苏。

### 背景旁白

### 转场

## Frame 2.2 · 同一段尾音

### 画面描述

**场景**【FPV·你的视角】：从你眼里看出去——隔着酒吧里几张暖橙灯下的空桌子；你的目光直接落到酒吧另一侧那个坐着的人身上
**人物**：

- 画面中（中远景）：他（赛博·他），坐在距你三五张桌子远的另一张小桌前；穿一件有冷光线条的雨衣、领口收得低；眼下一道极细的金属泪痕涂料在低悬的暖橙灯下反光；右手拢着一只酒杯没喝、左手指尖跟着收音机里那首老歌的节拍轻轻在桌沿上敲；目光没看你、看着自己面前那只酒杯里的暖橙倒影；右手腕上没有任何东西
**微动效**：他那一桌上的暖橙灯在他领口的冷光线条上一明一暗；他义体接驳点的散热口呼出极轻的一寸蓝光蒸汽又散开；你与他之间几张空桌子里漂着烟气

### 背景旁白

> 你的面前坐着一个男孩——
> 你觉得自己不认识她，
> 可你又像是，应该一直见到他。

### 对话

**她**（你的目光停在他身上）：「……没有人能够比我们更接近对方。」

**她**（你觉得熟悉又陌生）：「我为什么知道这个歌？」

**他**（在副歌的某一句无意识跟着哼了出来——像是他自己已经听过许多遍的歌）

**她**（你不自觉地屏住了呼吸——你记起来了一些事情，你的，和他的）

——【交互·选择型对话·跟不跟哼】——

- **A**（跟他一起唱）：**她**（你嘴唇极轻地动了一下——跟着那个尾音也无声地哼了半个音；声音轻到你自己都怀疑被酒吧的烟和酒气淹没了，可像是被这一桌一桌的暖橙灯连成的某根线捎了过去）
  - **他**（左手指尖在桌沿上敲的节拍突然停了一拍——他似乎听到了）
- **B**（默默看着他）：**她**（你没出声跟着哼；可你的目光没从他身上挪开半寸——你好像在哪见过他）
  - **他**（他敲完最后那一拍；忽然注意到了你，像是被你的心声唤住了）

### 转场

他停在桌沿上的左手指尖动了一下——他慢慢抬起头来 → 切下一帧（Frame 2.3）

## Frame 2.3 · 他看着你

**场景**【FPV·你的视角】：仍是隔着几张暖橙灯下的空桌子；他那张小桌前的他——已经把头抬完了、面正对着你、目光稳稳落在你身上
**人物**：

- 画面中（中远景）：他，正面对着你；眼下那道金属泪痕涂料在低悬的暖橙灯下又反了一下光；雨衣领口微敞、一截锁骨在冷光线条与暖橙灯交错的光里隐约可见；他停在桌沿的左手指尖已经落回桌上、安静地铺平；他的右手已经从酒杯上松开、自然地摊在桌沿
**微动效**：他领口的冷光线条微微一明一暗；他义体接驳点的散热口又呼出极轻的一寸蓝光蒸汽；你与他之间几张空桌子里漂着烟气；收音机里那首老歌的副歌已经落到了下一句

### 对话

### 转场

## Frame 2.4 · 他走过来

### 画面描述

**场景**【FPV·你的视角】：他已经走过那几张桌子的距离、停在你这一桌前；窗外是冷紫色的霓虹细雨，但窗内是干燥温暖的暖橙
**人物**：

- 画面中：他，已经走到你这一桌前；他没立刻坐下——左手刚搭上你对面那张椅子的椅背、把椅子向后拉开了半寸；嘴角带着一个还没绽出来就先按住了的笑——那个笑温柔、有少年气、像与这个赛博底层格格不入的另一个时空里的人；他的右手腕仍是空的；你的视角里他已经从远处的"剪影"变成了近处的"清晰的脸"
**微动效**：他义体接驳点的散热口又呼出极轻的一寸蓝光蒸汽；收音机里那首老歌已经唱到尾段、人声开始一点点散；你与他之间桌上那只小烛灯的火苗轻轻颤一下——像被他刚靠近的那一寸的呼吸颤到的

### 对话

**他**（他在你对面慢慢坐下——眼睛先落到你桌上那只小烛灯上、又抬起来落回到你身上）：「……你终于来啦？我点了你喜欢的歌。」

**她**（你的眼睛弯了一下）：「……真好听。」

**他**（看着你的眼睛出了神）：「……你的眼睛真好看。」

**她**（被他突然这么说；你的脸颊微微发热；你没说话）

**他**（他似乎很高兴）：「我喜欢这首歌的歌词。」

**他**（笑意里有一点少年气的认真）：「……写得很浪漫。」

**他**（他抬眼对上你；眼睛里是认真的——认真得不像是在问一个普通的问题）：「……你说——梦境的边缘、星河的中央，会是什么？」

**她**（你抬眼看他——他眼睛里那种"认真"让你的心跳轻轻漏了一拍；你抿了一下唇，没立刻答出来）

**他**（他没继续问；指尖在桌沿上轻轻敲了一下、像帮你打着拍子）：「……我记得，每年生日，你都说想离开这里。」

**他**（眼睛弯了一下；笑意里压着一点少年气的认真）：「……想不想和我一起去星河的中央？」

**她**（你想起了在这的一切，你们从小便是好友；也是恋人……）：「……当然想，可是在哪里呢？」

### 转场

他笑完后没再说话；他抬手——指了指你头顶上方那扇酒吧顶上嵌着的天窗 → 切下一帧（Frame 2.5）

## Frame 2.5 · 去月球

### 画面描述

**场景**【第三人称】：仍在酒吧里你与他对坐的小桌前；他的指尖向上指着——头顶那扇酒吧顶上嵌着的天窗（这是这家酒吧少数能让人抬头看见外面的窗）；透过它看见的是赛博之城的高楼广告投影——再之上，是一颗近得像伸手就能碰到、却其实没人真的开过去过的月球
**人物**：

- 中景左：你（赛博·她），坐在桌一侧；额前那缕头发已经被你顺到耳后；指尖按着自己右手腕的脉
- 中景右：他（赛博·他），坐在桌另一侧；一只手还指着那扇天窗、目光从天窗回到你身上；眼睛是认真的
**微动效**：那扇天窗外的霓虹细雨在玻璃上一颗一颗滑下、被霓虹光与月光打成两种颜色；月球在天窗里的位置因雨水折射稍稍晃了一下又稳住；你与他之间桌上那只小烛灯的火苗轻轻颤一下

### 对话

**他**（他抬手——指了指你头顶上方那扇酒吧顶上嵌着的天窗）：「……抬头」

**她**（你顺着他指的方向抬眼看过去——天窗、霓虹、那颗近得像在头顶的月球；你回头看他）：「……你是说真的？」

**他**（低悬的暖橙灯里，你能看见那一寸的认真）：「当然——你生日那天，我就带你离开地球，怎么样？」

——【交互·选择型对话·回答的语气】——

- **A**：**她**（你笑了一下，那个笑很轻；声音也很轻）：「……和你，我当然愿意。」
  - **他**（眼睛弯得更深一寸）：「……那从今晚起，你就是我星际航行的副舰长！」
- **B**：**她**（你抬眼看他；声音里带着一点说不清的迟疑）：「……你总给我画饼。」
  - **他**（他的目光稳稳落在你眼睛里、没躲；声音放得很轻一寸）：「……这次不会。」

**他**（他把指尖从天窗那头收回来、停在桌上靠你这一侧的位置；认真地看着你）：「明天——到我的车库来，给你看样东西。」

### 转场

他的指尖留在桌上没收回；你看了一眼他的指尖、又抬眼看了一眼头顶那扇天窗里那颗近得像伸手就能碰到的月球——画面淡出 0.5s → S03 Frame 3.1
